# 星の翼 スターパートナー 動画・配信申請アシスト（Chrome拡張機能）

YouTubeに投稿した動画を「スターパートナー」申請フォーム（wj.qq.com）へ
転記・送信する作業を半自動化するChrome拡張機能です。

## セットアップ

### 1. YouTube Data API キーの取得

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成（または既存のものを使用）
2. 「APIとサービス」→「ライブラリ」で **YouTube Data API v3** を有効化
3. 「認証情報」→「認証情報を作成」→「APIキー」でキーを発行
4. 自分のYouTubeチャンネルID（`UC`で始まる文字列）を控える
   （YouTube Studio の「詳細設定」や、チャンネルページのURLから確認できます）

### 2. ビルド

本体はTypeScriptで書かれており、Chromeで読み込む前にビルドが必要です。

```bash
npm install
npm run build
```

`dist/` フォルダに `manifest.json` を含む拡張機能一式が生成されます。
ソースを変更しながら試す場合は `npm run watch` で変更のたびに自動ビルドされます
（`npm run typecheck` で型エラーのみのチェックも可能）。

### 3. 拡張機能の読み込み

1. アドレスバーに `chrome://extensions` と入力してEnter
2. 画面右上の「デベロッパーモード」のトグルをONにする
   （OFFのままだと「パッケージ化されていない拡張機能を読み込む」ボタンが出ません）
3. 左上の「パッケージ化されていない拡張機能を読み込む」ボタンをクリック
4. フォルダ選択ダイアログで **`starpartner/dist`** フォルダそのものを選んで「フォルダーの選択」
   （`manifest.json` が直下にあるフォルダを選ぶ必要があります。`starpartner` フォルダ自体や
   `src` フォルダを選ぶとエラーになります）
5. 読み込みに成功すると拡張機能一覧に「星の翼 スターパートナー 動画・配信申請アシスト」のカードが表示されます
   - カードが赤字の「エラー」表示になっている場合はそこをクリックすると原因（manifestの記述ミスなど）が確認できます
6. 拡張機能一覧の右上の 拡張機能(パズルピースのアイコン) → 本拡張機能をピン留めすると
   ツールバーから使いやすくなります
7. ツールバーのアイコンをクリックするとダッシュボードが新規タブで開きます

**ソースを変更したときの反映方法**

1. `npm run build`（または `npm run watch` を動かしっぱなしにしておく）で `dist/` を更新
2. `chrome://extensions` の当該拡張機能カードにある円形の「再読み込み」アイコンをクリック
3. ダッシュボード/オプションのタブを開いたままだった場合は、そのタブ自体もリロードする
   （拡張機能の再読み込みだけでは開きっぱなしのページには反映されません）

**動作確認・デバッグ方法**

- ダッシュボード/オプション画面: そのページ上で右クリック→「検証」でDevToolsが開けます
- background(service worker): 拡張機能カードの「service worker」というリンクをクリックすると
  専用のDevToolsが開き、`console.log`やエラーを確認できます
- content script(`formFiller.ts`): wj.qq.comのフォームページ自体でDevToolsを開いて確認します

### 4. 初期設定

拡張機能アイコンを右クリック→「オプション」（またはダッシュボード右上の「設定を開く」）から:

- YouTubeチャンネル名（フォームに転記する登録ニックネーム）
- DiscordのID
- YouTube Data APIキー
- 自分のチャンネルID
- 検索キーワード（カンマ区切り。運営指定のタグなど）
- 投稿内容カテゴリの自動推測ルール（タイトルのキーワード対応表）

を入力して保存してください。

## 使い方

1. ダッシュボードで対象年月を選び「動画を取得」
2. 一覧に取得した動画が表示され、ビデオタイプ・投稿内容カテゴリは自動推測されます
   （プルダウンで手動修正可能。動画リンクもテキストで編集できます）
3. 送信済みの動画は自動でグレーアウトされ、デフォルトでは選択対象から外れます
4. 送信したい動画にチェックを入れ、「選択した動画を一括送信」をクリック
5. 拡張機能が1件ずつフォームのタブを開いて自動入力・送信します。
   途中でエラーが起きた場合は自動送信を止め、該当タブを開いたままにするので
   手動で確認・完了させてください

## 注意事項・既知の制約

- フォーム送信は**完全無人の連続送信ではなく**、ユーザーが一覧で確認・選択した上で
  実行する半自動方式です。失敗時は安全のためキューを停止します。
- `src/content/formFiller.ts` はwj.qq.comの実際のDOM構造を2026年9月時点で調査して
  実装したものです。フォーム側の実装が変わった場合は動かなくなる可能性があるため、
  その際はセレクタの見直しが必要です。
- YouTube検索はAPIキーのみで認証しており、**公開動画のみ**が対象です。
  限定公開/非公開動画は取得できません。
- 検索キーワードによる絞り込みは**動画タイトルのみ**を対象にしています。
  概要欄(description)は対象外です（全動画共通のハッシュタグ・署名などを
  概要欄に入れているとキーワード絞り込みが効かなくなるため）。
- 実際に本番フォームへ送信する前に、まず1件だけで一括送信を試し、
  wj.qq.com側で正しく入力・送信されていることを目視確認してください。
