使い方ガイド

最終更新日: 2026年9月23日

「星の翼 スターパートナー 動画・配信申請アシスト」は、YouTubeに投稿した動画を「スターパートナー」プログラムの 申請フォームへ登録する作業を半自動化するChrome拡張機能です。このページでは、インストールから 実際に使うまでの手順を説明します。

  2. 初期設定

1. インストール

  1. Chromeウェブストアの「星の翼 スターパートナー 動画・配信申請アシスト」のページを開く
  2. 「Chromeに追加」をクリック
  3. 確認ダイアログが出たら「拡張機能を追加」をクリック

インストール後、Chromeのツールバー右上の パズルピースのアイコン（拡張機能） から 本拡張機能を見つけてピン留めしておくと、次回から使いやすくなります。

2. 初期設定

インストール後、最初に設定画面（オプションページ）で以下を入力する必要があります。 拡張機能のアイコンを右クリック →「オプション」、または拡張機能アイコンをクリックして 開くダッシュボード画面右上の「設定を開く」から設定画面に入れます。

2-1. 申請フォームURL（最重要）

このツールには申請フォームのURLは含まれていません。ゲーム運営・プログラム管理者から 個別に案内されたURLを、ご自身で入力してください。URLが分からない場合は、 スターパートナープログラムの担当窓口にお問い合わせください。

2-2. YouTubeチャンネル名・Discord ID

  • YouTubeチャンネル名: 申請フォームにいつも記入している登録ニックネームを入力してください
  • Discordの個人ID: Discordのデフォルト数字IDではなく、ご自身で設定したユーザー名を入力してください

2-3. YouTube Data APIキーの取得

動画情報を自動取得するために、ご自身のGoogleアカウントでAPIキーを発行する必要があります。 無料で取得できます。

  1. Google Cloud Console を開き、Googleアカウントでログイン
  2. 画面上部のプロジェクト選択メニューから「新しいプロジェクト」を作成（名前は何でも構いません）
  3. 左メニュー「APIとサービス」→「ライブラリ」を開く
  4. 検索欄に YouTube Data API v3 と入力して検索し、表示された項目を開く
  5. 「有効にする」をクリック
  6. 左メニュー「APIとサービス」→「認証情報」を開く
  7. 「+ 認証情報を作成」→「APIキー」を選択
  8. 表示されたAPIキーをコピーし、拡張機能の設定画面「APIキー」欄に貼り付け
請求先アカウント（クレジットカード）の登録を求められる場合がありますが、YouTube Data API v3は 1日10,000ユニットまで無料で利用できる範囲内であれば課金は発生しません。

2-4. 自分のYouTubeチャンネルIDの確認

以下のいずれかの方法で確認できます。

  1. YouTube Studioから（確実）: YouTube Studio を開く → 左下の「設定」→「チャンネル」→「詳細設定」→ UC から始まる「チャンネルID」をコピー
  2. チャンネルページのURLから: 自分のチャンネルページのURLが https://www.youtube.com/channel/UCxxxxxxxxxxxxxxxxxxxxxx の形式なら、 その UCxxxxxxxxxxxxxxxxxxxxxx の部分がチャンネルIDです （@名前 形式のカスタムURLの場合はこの方法では確認できないため、上記のYouTube Studioの方法を使ってください）

2-5. 検索キーワード・カテゴリ自動推測ルール

検索キーワード欄には、申請対象の動画に必ず含めているタグ・キーワード（例: 運営指定のハッシュタグ）を 入力してください。ここに入れたキーワードが動画タイトルに含まれる動画だけが取得対象になります。

「投稿内容カテゴリの自動推測ルール」は、動画タイトルに含まれる単語から申請フォームの 「投稿内容」欄の選択肢を自動で推測するための設定です。デフォルトである程度用意されていますが、 ご自身の投稿傾向に合わせて調整してください（一覧画面で毎回手動修正も可能です）。

すべて入力したら「保存」を押してください。

3. 使い方

  1. 拡張機能アイコンをクリックしてダッシュボードを開く
  2. 「対象年月」を選び、「動画を取得」をクリック
  3. 設定したキーワードを含む動画が一覧表示されます。ビデオタイプ・投稿内容カテゴリは自動推測されるので、内容を確認し、必要であればプルダウンで修正してください
  4. 送信したい動画にチェックを入れる（送信済みの動画は自動的にグレーアウトされ、対象から外れます）
  5. 「選択した動画を一括送信」をクリック
  6. 拡張機能が1件ずつ申請フォームのタブを自動で開き、入力・送信します。完了すると一覧の「状態」欄が更新されます
全自動で無人送信され続けるわけではありません。 何らかの理由で入力・送信に失敗した場合は、そこで自動処理が止まり、該当のタブが開いたままになります。 その場合はタブの内容を確認し、手動で完了させてから、必要であれば残りの動画を選び直してもう一度 「一括送信」を実行してください。

4. よくある質問・困ったときは

Q. 動画が1件も取得できない

  • 設定画面のAPIキー・チャンネルID・検索キーワードが正しいか確認してください
  • 検索キーワードは動画のタイトルに含まれている必要があります（概要欄は対象外です）
  • 対象年月の選択が正しいか確認してください

Q. フォームへの入力の途中でエラーになる

  • 申請フォームURLが正しいか、設定画面で確認してください
  • フォーム側の仕様変更などで自動入力が動かなくなっている可能性があります。エラーメッセージの内容とあわせて、開発者にご連絡ください

Q.「以前の入力を続けますか？」という確認画面が出た

これは申請フォーム側の仕様で、以前に途中まで入力した記録が残っていると表示されます。 本拡張機能は自動的に「最初から」を選んで進めるので、通常は気にする必要はありません。

Q. 同じ動画を二重に申請してしまわないか心配

送信が完了した動画は拡張機能内に記録され、次回以降の一覧では自動的に「送信済み」表示になり、 デフォルトでは選択対象から外れます（手動でチェックを入れれば再送信も可能です）。
